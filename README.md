# Xtream TV Player

Android TV IPTV player for Xtream Codes accounts (live TV with EPG, movies, series).

**Install on the TV:** open the Downloader app and enter

https://github.com/osamaaabualwafa/xtream-tv-player/releases/latest/download/xtream-tv-player.apk

The APK is built by GitHub Actions on every push to `main` and published as a release.
